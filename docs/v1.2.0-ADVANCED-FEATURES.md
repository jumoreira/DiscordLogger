# DiscordLogger v1.2.0 - Recursos Avançados

Esta versão adiciona recursos avançados ao DiscordLogger, incluindo suporte a scopes, batching de mensagens, filtros avançados e formatadores personalizados.

## 🎯 Recursos Novos

### 1. Log Scopes Completos

Os scopes permitem adicionar contexto adicional aos logs, como IDs de requisição, usuários, etc.

```csharp
services.AddLogging(builder =>
{
    builder.AddDiscord(options =>
    {
        options.WebhookUrl = "YOUR_WEBHOOK_URL";
        options.EnableScopes = true; // Habilita suporte a scopes
    });
});

var logger = serviceProvider.GetRequiredService<ILogger<Program>>();

using (logger.BeginScope("RequestId: {RequestId}", "12345"))
{
    using (logger.BeginScope("UserId: {UserId}", "user@example.com"))
    {
        logger.LogInformation("Processando requisição");
        // O log incluirá: RequestId=12345, UserId=user@example.com
    }
}
```

**Características:**
- Scopes aninhados suportados
- Serialização automática de estado
- Formatação elegante no Discord

### 2. Batching de Mensagens

Agrupa múltiplas mensagens em um único envio para o Discord, reduzindo chamadas de API e melhorando a performance.

```csharp
services.AddLogging(builder =>
{
    builder.AddDiscord(options =>
    {
        options.WebhookUrl = "YOUR_WEBHOOK_URL";
        
        // Configuração de batching
        options.Batching.Enabled = true;
        options.Batching.MaxBatchSize = 10; // Até 10 mensagens por batch
        options.Batching.FlushIntervalSeconds = 5; // Flush automático a cada 5s
        options.Batching.MaxQueueSize = 1000; // Tamanho máximo da fila
    });
});

// Múltiplas mensagens serão agrupadas automaticamente
for (int i = 0; i < 20; i++)
{
    logger.LogInformation("Mensagem #{Number}", i);
}
```

**Características:**
- Flush automático por tempo ou quantidade
- Queue thread-safe usando `Channel<T>`
- Background worker para processamento assíncrono
- Limite de 10 embeds por mensagem (limitação do Discord)

### 3. Filtros Avançados

Filtre logs por categoria, EventId, padrões de mensagem e mais.

```csharp
services.AddLogging(builder =>
{
    builder.AddDiscord(options =>
    {
        options.WebhookUrl = "YOUR_WEBHOOK_URL";
        
        // Filtro por categoria
        options.Filters.IncludeCategories.Add("MyApp.*"); // Whitelist
        options.Filters.ExcludeCategories.Add("MyApp.Verbose*"); // Blacklist
        
        // Filtro por EventId
        options.Filters.IncludeEventIds.Add(100);
        options.Filters.ExcludeEventIds.Add(404);
        
        // Filtro por padrão de mensagem (regex)
        options.Filters.MessagePatterns.Add("User logged in.*");
        options.Filters.MessagePatternsAsWhitelist = false; // Blacklist mode
        
        // Filtro por nível de log
        options.Filters.EnabledLevels[LogLevel.Information] = true;
        options.Filters.EnabledLevels[LogLevel.Debug] = false;
    });
});
```

**Características:**
- Suporte a wildcards (`*`) em categorias
- Expressões regulares para padrões de mensagem
- Modos whitelist e blacklist
- Filtros combinados (todos devem passar)

### 4. Formatadores Personalizados

Personalize completamente a aparência das mensagens no Discord.

#### Formatador Padrão

```csharp
options.MessageFormatter = new DefaultMessageFormatter();
```

#### Formatador com Templates

```csharp
options.MessageFormatter = new TemplateMessageFormatter(
    titleTemplate: "🎯 [{level}] - {date}",
    descriptionTemplate: "⏰ {time} | {message}"
);
```

**Placeholders disponíveis:**
- `{level}` - Nível do log (Debug, Information, etc.)
- `{emoji}` - Emoji do nível (🔍, ℹ️, ⚠️, ❌, 🔥)
- `{message}` - Mensagem do log
- `{timestamp}` - Timestamp completo (yyyy-MM-dd HH:mm:ss)
- `{date}` - Data (yyyy-MM-dd)
- `{time}` - Hora (HH:mm:ss)
- `{exception}` - Nome da exceção (se houver)

#### Formatador Customizado

Implemente `IMessageFormatter` para controle total:

```csharp
public class MyCustomFormatter : IMessageFormatter
{
    public DiscordWebhookMessage FormatMessage(
        LogLevel level,
        string message,
        Exception? exception,
        DiscordLoggerOptions options,
        string? scopeInfo = null)
    {
        // Sua lógica personalizada aqui
        return new DiscordWebhookMessage
        {
            Username = options.Username,
            Embeds = new List<DiscordEmbed> { /* ... */ }
        };
    }

    public DiscordWebhookMessage FormatBatch(
        IList<(LogLevel Level, string Message, Exception? Exception)> messages,
        DiscordLoggerOptions options)
    {
        // Sua lógica para batches
    }
}

// Uso
options.MessageFormatter = new MyCustomFormatter();
```

## 📊 Exemplo Completo

```csharp
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Logging;
using DiscordLogger;
using DiscordLogger.Formatters;

var services = new ServiceCollection();

services.AddLogging(builder =>
{
    builder.AddDiscord(options =>
    {
        options.WebhookUrl = "YOUR_WEBHOOK_URL";
        options.Username = "SuperBot";
        options.AvatarUrl = "https://example.com/avatar.png";
        
        // Habilita scopes
        options.EnableScopes = true;
        
        // Configura batching
        options.Batching.Enabled = true;
        options.Batching.MaxBatchSize = 5;
        options.Batching.FlushIntervalSeconds = 10;
        
        // Configura filtros
        options.Filters.IncludeCategories.Add("MyApp.*");
        options.Filters.ExcludeEventIds.Add(404);
        
        // Formatador personalizado
        options.MessageFormatter = new TemplateMessageFormatter(
            titleTemplate: "{emoji} [{level}] {exception}",
            descriptionTemplate: "{timestamp} - {message}"
        );
    });
});

var serviceProvider = services.BuildServiceProvider();
var logger = serviceProvider.GetRequiredService<ILogger<Program>>();

// Uso com scopes
using (logger.BeginScope("CorrelationId: {CorrelationId}", Guid.NewGuid()))
{
    logger.LogInformation("Processando requisição");
    
    try
    {
        // Sua lógica aqui
    }
    catch (Exception ex)
    {
        logger.LogError(ex, "Erro durante processamento");
    }
}
```

## 📈 Performance

### Sem Batching
- Cada log = 1 chamada HTTP ao Discord
- 100 logs = 100 requisições

### Com Batching (MaxBatchSize = 10)
- Até 10 logs = 1 chamada HTTP
- 100 logs = ~10 requisições
- **Redução de ~90% nas chamadas de API**

## 🎓 Melhores Práticas

1. **Use Scopes** para contexto adicional em aplicações web/API
2. **Habilite Batching** em ambientes de alta volumetria
3. **Configure Filtros** para evitar spam de logs desnecessários
4. **Personalize Formatadores** para match com sua identidade visual
5. **Combine recursos** para máxima eficiência

## 🔄 Migração da v1.1.0

A v1.2.0 é **totalmente compatível** com v1.1.0. Todos os recursos antigos continuam funcionando.

Para usar os novos recursos, simplesmente adicione as configurações desejadas:

```csharp
// v1.1.0 (ainda funciona)
builder.AddDiscord(options =>
{
    options.WebhookUrl = "YOUR_WEBHOOK_URL";
});

// v1.2.0 (com novos recursos)
builder.AddDiscord(options =>
{
    options.WebhookUrl = "YOUR_WEBHOOK_URL";
    options.EnableScopes = true; // Novo
    options.Batching.Enabled = true; // Novo
    // ...
});
```

## 📝 Notas

- O batching é **desabilitado por padrão** para manter compatibilidade
- Scopes são **desabilitados por padrão**
- O formatador padrão é usado se nenhum for especificado
- Filtros só são aplicados se configurados

## 🐛 Troubleshooting

### Scopes não aparecem nos logs
- Verifique se `EnableScopes = true`
- Verifique se está usando `logger.BeginScope()`

### Batches não são enviados
- Verifique se `Batching.Enabled = true`
- Aguarde o `FlushIntervalSeconds` ou envie `MaxBatchSize` mensagens

### Filtros não funcionam
- Verifique os padrões (wildcards, regex)
- Lembre-se: blacklist tem precedência sobre whitelist
